# 📊 Customer Retention & Churn Analysis Dashboard

## Project Overview

This project analyzes customer churn behavior using Power BI.
The goal is to identify factors influencing customer retention and churn.

## Objectives

- Analyze customer churn patterns
- Identify high-risk customer segments
- Understand factors affecting retention
- Provide actionable business insights

## Tools Used

- Power BI
- Power Query
- Data Cleaning
- Data Visualization

## Dashboard Features

### KPI Analysis
- Total Customers
- Churned Customers
- Retained Customers

### Churn Analysis
- Contract type impact
- Payment method analysis
- Internet service analysis

### Customer Insights
- Churn distribution
- Customer lifetime vs monthly charges

## Key Insights

- 26.5% customers have churned.
- Month-to-month contracts show the highest churn.
- Electronic check users have higher churn risk.
- Long-term customers show better retention.
